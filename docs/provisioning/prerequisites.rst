Prérequis
==========

Systèmes d'exploitation supportés
------------------------------------

- Debian 12
- Ubuntu Server 24.04 LTS

Prérequis généraux
-------------------

- accès ``root`` ou ``sudo`` sur chaque nœud
- connectivité réseau inter-nœuds
- horloge système fonctionnelle
- interfaces réseau identifiées avant installation
