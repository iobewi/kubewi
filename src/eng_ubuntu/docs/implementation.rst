Implémentation
==============

``eng_ubuntu`` est un paquet **placeholder**. Le playbook ``provision.yml``
existe mais le rôle Ubuntu n'est pas encore implémenté.

La structure suit exactement celle de ``eng_debian`` — à compléter lorsque
les nœuds Ubuntu seront intégrés à la plateforme (drivers Intel DPDK,
OpenVINO, ou stack x86 générique).
